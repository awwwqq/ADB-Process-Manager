About this preview

Windows + Android over ADB. No root or companion app required. All telemetry and change history stay local. Network, per-app battery, disk activity, and GPU usage are not estimated when reliable measurements are unavailable.

Force stop is available for user apps. Essential packages are protected. System removal is limited to the reviewed Xiaomi advertising, analytics, app-finder, and App Vault packages; other system packages are inspection-only.
